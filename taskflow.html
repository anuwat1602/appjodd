iOS (Safari) วิธีเพิ่มลงหน้าจอ iPhone / iPad

1. เปิดเว็บนี้ผ่านเบราว์เซอร์ Safari
2. แตะปุ่ม แชร์ (Share) ด้านล่างหน้าจอ
3. เลื่อนลงแล้วเลือก "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)

Android (Chrome) วิธีติดตั้งบนมือถือ Android

1. เปิดเว็บนี้ผ่าน Google Chrome
2. แตะเมนู จุด 3 จุด (⋮) มุมขวาบน
3. เลือก "เพิ่มลงในหน้าจอหลัก" หรือ "ติดตั้งแอป"

ไฟล์สำหรับ Deploy (PWA & Icons)

ดาวน์โหลดไฟล์ทั้งหมดไปวางในโฟลเดอร์เดียวกับ index.html

1. ดาวน์โหลดไฟล์ครบชุดสำหรับอัปโหลดขึ้นโฮสต์ (Vercel / Netlify / GitHub Pages)

2. โค้ดสำหรับใส่ใน <head> ของ index.html 
<link rel="manifest" href="manifest.json">
<link rel="apple-touch-icon" href="icon-192.png">
<meta name="theme-color" content="#064e3b">
3. เนื้อหาไฟล์ manifest.json
